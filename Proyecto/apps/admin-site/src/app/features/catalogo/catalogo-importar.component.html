Importar catálogo desde Excel

Volver al catálogo
  1. Descarga la plantilla vacía para cargar productos nuevos, o el catálogo actual para editar en masa lo que ya existe. El SKU es la llave: si ya existe se actualiza el producto, si no se crea. En una actualización, las celdas vacías no se modifican.
  2. Sube la planilla y revisa la simulación: no se guarda nada hasta que confirmes.
  3. Confirma la importación. Las filas con error se omiten y puedes corregirlas y volver a cargar el archivo.
