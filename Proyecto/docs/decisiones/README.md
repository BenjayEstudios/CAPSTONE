# Decisiones

Decisiones de producto y técnicas que cruzan varias épicas. Las que son
propias de una sola épica viven en el archivo de esa épica, en
[../epicas/](../epicas/README.md).

- [DECISIONES-ABIERTAS.md](DECISIONES-ABIERTAS.md) — lo que falta resolver,
  con la épica/ticket en que aplica y qué bloquea.
- [DECISIONES-CERRADAS.md](DECISIONES-CERRADAS.md) — lo ya resuelto, con el
  motivo. Sirve para no re-litigar lo mismo en conversaciones futuras.

Cuando una decisión abierta se resuelve, se mueve a cerradas **con su motivo**,
no solo con el resultado.
